В задачах сортировку почти никогда не пишут вручную: в Python есть встроенная, и она работает за $O(n \log n)$. Главное – уметь ею пользоваться.

## sort() и sorted()

- `a.sort()` – метод списка. Сортирует **сам список** и ничего не возвращает.
- `sorted(a)` – функция. Возвращает **новый** отсортированный список, а исходный не меняет.

```python
a = [3, 1, 2]
b = sorted(a)
print(a, b)   # [3, 1, 2] [1, 2, 3]

a.sort()
print(a)      # [1, 2, 3]
```

Частая ошибка:

```python
a = [3, 1, 2]
a = a.sort()   # ❌ sort() возвращает None
print(a)       # None
```

Функция `sorted()` принимает любую последовательность, например строку. Результат – всегда список:

```python
print(sorted("hello"))            # ['e', 'h', 'l', 'l', 'o']
print("".join(sorted("hello")))   # ehllo
```

## По убыванию: reverse

```python
a = [3, 1, 2]
print(sorted(a, reverse=True))   # [3, 2, 1]
a.sort(reverse=True)             # то же для метода
```

## Свой порядок: key

Параметр `key` – это функция, которая вызывается для каждого элемента. Элементы сравниваются не сами по себе, а по результату этой функции (см. [Функции](<Функции>)).

```python
words = ["банан", "киви", "яблоко", "инжир"]
print(sorted(words, key=len))   # ['киви', 'банан', 'инжир', 'яблоко']

nums = [-5, 3, -1, 4]
print(sorted(nums, key=abs))    # [-1, 3, 4, -5]

nums = [25, 13, 41, 7]
print(sorted(nums, key=lambda x: x % 10))   # [41, 13, 25, 7] – по последней цифре
```

### Строки и регистр

Строки сравниваются по кодам символов, поэтому заглавные буквы идут раньше строчных (см. [Строки](<Строки>)):

```python
names = ["bob", "Alice", "Carl", "dave"]
print(sorted(names))                  # ['Alice', 'Carl', 'bob', 'dave']
print(sorted(names, key=str.lower))   # ['Alice', 'bob', 'Carl', 'dave']
```

### Числа в виде строк

Если числа прочитаны как строки и не преобразованы, они отсортируются как слова:

```python
a = ["10", "9", "100"]
print(sorted(a))            # ['10', '100', '9']
print(sorted(a, key=int))   # ['9', '10', '100']
```

## Сортировка по нескольким признакам

Кортежи сравниваются как слова в словаре: сначала первые элементы, при равенстве – вторые, и так далее.

```python
print((2, "b") < (3, "a"))   # True – решает первый элемент
print((2, "a") < (2, "b"))   # True – первые равны, решает второй
```

Поэтому если `key` возвращает кортеж, элементы сортируются сначала по первому признаку, при равенстве – по второму.

**Пример.** Таблица результатов: сортируем по баллам по убыванию, а при равных баллах – по фамилии по алфавиту. Чтобы числа шли по убыванию, берём их со знаком минус:

```python
students = [("Иванов", 250), ("Петров", 300), ("Алексеев", 250), ("Сидоров", 180)]
students.sort(key=lambda s: (-s[1], s[0]))
for name, score in students:
    print(name, score)
```

```no-highlight
Петров 300
Алексеев 250
Иванов 250
Сидоров 180
```

## Устойчивость

Сортировка в Python **устойчивая**: элементы с одинаковым ключом остаются в том же порядке, в каком были до сортировки. Например, выше в `sorted(words, key=len)` слова «банан» и «инжир» одной длины остались в исходном порядке.

Благодаря устойчивости сортировку по нескольким признакам можно сделать в два прохода: **сначала по второстепенному признаку, потом по главному**. Это удобно, когда «минус» не помогает – например, если строки нужно отсортировать по убыванию.

```python
students = [("Иванов", 250), ("Петров", 300), ("Алексеев", 250), ("Сидоров", 180)]
students.sort(key=lambda s: s[0])                 # сначала по фамилии
students.sort(key=lambda s: s[1], reverse=True)   # потом по баллам
# результат тот же: Петров, Алексеев, Иванов, Сидоров
```

## Сложность

Встроенная сортировка работает за $O(n \log n)$: $10^5$ чисел сортируются за доли секунды. Внутри неё алгоритм Timsort, который особенно быстро работает на почти отсортированных данных.

## Типичные приёмы

**Анаграммы.** Два слова – анаграммы, если состоят из одних и тех же букв. После сортировки букв они совпадут:

```python
print(sorted("листок") == sorted("столик"))   # True
```

**Медиана и k-е по возрастанию число.** После сортировки медиана стоит в середине, а k-е по возрастанию число – на позиции `k - 1`:

```python
a = sorted([7, 1, 5, 3, 9])
print(a[len(a) // 2])   # 5 – медиана
k = 2
print(a[k - 1])         # 3 – второе по возрастанию
```

**Одинаковые элементы рядом.** Чтобы проверить, есть ли в массиве повторы, достаточно отсортировать его и сравнить соседей – $O(n \log n)$ вместо $O(n^2)$:

```python
a = sorted(a)
has_duplicates = False
for i in range(len(a) - 1):
    if a[i] == a[i + 1]:
        has_duplicates = True
        break
```

## Шпаргалка

| Что нужно | Код |
| --------- | --- |
| новый отсортированный список | `sorted(a)` |
| отсортировать сам список | `a.sort()` |
| по убыванию | `sorted(a, reverse=True)` |
| по длине | `sorted(words, key=len)` |
| без учёта регистра | `sorted(words, key=str.lower)` |
| строки-числа как числа | `sorted(a, key=int)` |
| по своему правилу | `sorted(a, key=lambda x: x % 10)` |
| по убыванию числа, затем по имени | `key=lambda s: (-s[1], s[0])` |
| буквы строки по порядку | `"".join(sorted(s))` |
