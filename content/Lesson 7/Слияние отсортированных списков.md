**Задача.** Даны два списка, каждый из них отсортирован по возрастанию. Нужно получить один общий отсортированный список.

Простое решение – `sorted(a + b)` – работает за $O((n + m) \log (n + m))$. Но оно никак не использует то, что списки уже отсортированы. Можно быстрее.

## Идея: два указателя

Заведём два указателя: `i` – на начало списка `a`, `j` – на начало списка `b`. Самый маленький из всех ещё не взятых элементов – это либо `a[i]`, либо `b[j]`. Сравниваем их, меньший добавляем в результат и сдвигаем его указатель вправо. Когда один из списков закончится, дописываем остаток другого.

```python
def merge(a, b):
    i, j = 0, 0
    result = []
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            result.append(a[i])
            i += 1
        else:
            result.append(b[j])
            j += 1
    result += a[i:]
    result += b[j:]
    return result
```

```python
print(merge([1, 4, 7], [2, 3, 9]))   # [1, 2, 3, 4, 7, 9]
```

Разберём пример по шагам:

| `i` | `j` | `a[i]` | `b[j]` | Берём | `result` |
| --- | --- | ------ | ------ | ----- | -------- |
| 0 | 0 | 1 | 2 | 1 из `a` | `[1]` |
| 1 | 0 | 4 | 2 | 2 из `b` | `[1, 2]` |
| 1 | 1 | 4 | 3 | 3 из `b` | `[1, 2, 3]` |
| 1 | 2 | 4 | 9 | 4 из `a` | `[1, 2, 3, 4]` |
| 2 | 2 | 7 | 9 | 7 из `a` | `[1, 2, 3, 4, 7]` |

Список `a` закончился, дописываем остаток `b`: `[1, 2, 3, 4, 7, 9]`.

## Сложность

Каждое сравнение добавляет в результат ровно один элемент, а каждый указатель двигается только вперёд. Поэтому всего не больше $n + m$ шагов – сложность $O(n + m)$.

## Метод двух указателей

Приём «два указателя идут по спискам и каждый двигается только вперёд» встречается во многих задачах: найти общие элементы двух отсортированных списков, найти пару чисел с заданной суммой, найти подотрезок с нужным свойством. Мы ещё не раз к нему вернёмся.

> [!note] Примечание
> Слияние – главная часть **сортировки слиянием**: массив делят пополам, каждую половину сортируют, а затем две отсортированные половины сливают. Эта сортировка работает за $O(n \log n)$, но для неё нужна рекурсия, поэтому мы разберём её позже.
