Все простые сортировки сравнивают элементы между собой. Можно доказать, что любой сортировке, которая только сравнивает элементы, в худшем случае нужно порядка $n \log n$ сравнений – быстрее не получится.

Но если элементы – **небольшие целые числа**, сравнивать их вообще не нужно. Достаточно посчитать, сколько раз встречается каждое число.

Пример: 1000 студентов получили оценки от 2 до 5. Чтобы отсортировать оценки, достаточно узнать, сколько получено двоек, троек, четвёрок и пятёрок, и выписать их по порядку.

## Идея

Пусть все числа лежат в диапазоне от $0$ до $k$.

1. Заводим список `count` из $k + 1$ нулей: `count[v]` – сколько раз встретилось число `v`.
2. Один раз проходим по массиву и для каждого числа `x` увеличиваем `count[x]`.
3. Проходим по `v` от $0$ до $k$ и выписываем каждое `v` ровно `count[v]` раз.

```python
def counting_sort(a, k):
    count = [0] * (k + 1)
    for x in a:
        count[x] += 1
    result = []
    for v in range(k + 1):
        for _ in range(count[v]):
            result.append(v)
    return result
```

```python
a = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3]
print(counting_sort(a, 9))   # [1, 1, 2, 3, 3, 4, 5, 5, 6, 9]
```

## Сложность

Проход по массиву – $n$ операций, проход по счётчикам – $k + 1$ операций, выписывание – ещё $n$. Итого $O(n + k)$. Памяти нужно $O(k)$ – под список `count`.

Если $k$ маленькое, это быстрее любой сортировки сравнениями: для миллиона оценок от 2 до 5 – около двух миллионов простых операций.

## Когда подходит

| Данные | Подходит? |
| ------ | --------- |
| целые числа из небольшого диапазона: оценки, возраст, цифры | ✅ да |
| символы строки (через `ord()`) | ✅ да |
| числа до $10^9$ | ❌ нет: список `count` из миллиарда элементов не поместится в память |
| вещественные числа, строки | ❌ нет |

## Отрицательные числа

Если числа лежат в диапазоне от `min_value` до `max_value` и могут быть отрицательными, индекс в `count` сдвигают: число `x` хранится в `count[x - min_value]`.

```python
def counting_sort(a, min_value, max_value):
    count = [0] * (max_value - min_value + 1)
    for x in a:
        count[x - min_value] += 1
    result = []
    for v in range(len(count)):
        for _ in range(count[v]):
            result.append(v + min_value)
    return result


print(counting_sort([3, -2, 0, -2, 5], -2, 5))   # [-2, -2, 0, 3, 5]
```

**Запомни:** часто сам отсортированный массив и не нужен. Если в задаче спрашивают «сколько раз встречается каждое число» – ответ уже лежит в списке `count`.
