## Задание 11. Эксперимент

Сравните скорость своей сортировки пузырьком и встроенной `sorted()`. Для каждого `n` из таблицы создайте список из `n` случайных чисел и замерьте время обеих сортировок:

```python
import random
import time

n = 1000
a = [random.randint(1, 10**6) for _ in range(n)]

start = time.perf_counter()
bubble_sort(a.copy())
print("пузырёк:", time.perf_counter() - start)

start = time.perf_counter()
sorted(a)
print("sorted:", time.perf_counter() - start)
```

Заполните таблицу:

| `n` | Пузырёк, с | `sorted()`, с |
| --- | ---------- | ------------- |
| 1000 | | |
| 2000 | | |
| 4000 | | |

Во сколько раз растёт время пузырька, когда `n` увеличивается вдвое? Объясните, почему (см. [Сложность алгоритмов](<Сложность алгоритмов>)).
