**Сортировка** – это расстановка элементов по порядку: по возрастанию, по убыванию или по любому другому правилу.

В отсортированном массиве многое делается проще и быстрее: минимум и максимум стоят по краям, одинаковые элементы оказываются рядом, медиана находится ровно в середине. Поэтому сортировка – первый шаг в решении огромного количества задач.

В Python есть готовая функция `sorted()` (см. [Встроенная сортировка](<Встроенная сортировка>)). Но разобрать, как сортировка устроена внутри, полезно: на простых сортировках хорошо видно, откуда берётся сложность $O(n^2)$, а их идеи встречаются и в других алгоритмах.

> [!tip] Как пользоваться анимациями
> «Шаг ▶» выполняет одно действие алгоритма, «◀ Назад» возвращает на шаг назад, «▶ Авто» проигрывает всё целиком. Рядом подсвечивается строка кода, которая выполняется сейчас, а внизу считаются сравнения и обмены. Можно нажимать стрелки ← → и пробел.

## Сортировка пузырьком

**Идея:** идём по массиву слева направо и сравниваем соседние элементы. Если левый больше правого – меняем их местами. За один такой проход самый большой элемент «всплывает» в конец массива, как пузырёк. Повторяем проходы, каждый раз не трогая уже всплывшие элементы.

```python
def bubble_sort(a):
    n = len(a)
    for i in range(n - 1):
        for j in range(n - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
```

<iframe src="sort-viz.htm#bubble" title="Анимация: сортировка пузырьком" style="width: 100%; height: 480px; border: none;"></iframe>

Функция изменяет сам список и ничего не возвращает – так же, как метод `sort()`:

```python
a = [5, 1, 4, 2]
bubble_sort(a)
print(a)   # [1, 2, 4, 5]
```

Разберём сортировку этого массива по шагам:

| Проход | Сравниваем | Действие | Массив после |
| ------ | ---------- | -------- | ------------ |
| 1 | 5 и 1 | меняем | `[1, 5, 4, 2]` |
| 1 | 5 и 4 | меняем | `[1, 4, 5, 2]` |
| 1 | 5 и 2 | меняем | `[1, 4, 2, 5]` – 5 на своём месте |
| 2 | 1 и 4 | оставляем | `[1, 4, 2, 5]` |
| 2 | 4 и 2 | меняем | `[1, 2, 4, 5]` – 4 на своём месте |
| 3 | 1 и 2 | оставляем | `[1, 2, 4, 5]` – готово |

**Сложность.** Внешний цикл делает $n - 1$ проходов, внутренний – сначала $n - 1$ сравнений, потом $n - 2$, и так до одного. Всего $\frac{n(n-1)}{2}$ сравнений, то есть $O(n^2)$.

### Улучшение: досрочный выход

Если за весь проход не было ни одного обмена, массив уже отсортирован, и дальше проверять незачем:

```python
def bubble_sort(a):
    n = len(a)
    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
                swapped = True
        if not swapped:
            break
```

На уже отсортированном массиве такая версия сделает всего один проход – $O(n)$.

## Сортировка выбором

**Идея:** находим минимум во всём массиве и ставим его на первое место (меняем местами с первым элементом). Затем ищем минимум среди оставшихся и ставим его на второе место, и так далее. Слева растёт уже готовая часть массива.

```python
def selection_sort(a):
    n = len(a)
    for i in range(n - 1):
        m = i
        for j in range(i + 1, n):
            if a[j] < a[m]:
                m = j
        a[i], a[m] = a[m], a[i]
```

Здесь `m` – индекс минимального элемента среди `a[i]`, `a[i + 1]`, ..., `a[n - 1]`.

<iframe src="sort-viz.htm#selection" title="Анимация: сортировка выбором" style="width: 100%; height: 480px; border: none;"></iframe>

**Сложность.** Сравнений всегда $\frac{n(n-1)}{2}$ – даже если массив уже отсортирован, минимум всё равно приходится искать. Поэтому $O(n^2)$ в любом случае. Зато обменов ровно $n - 1$: это удобно, когда переставлять элементы дорого.

## Сортировка вставками

**Идея:** так сортируют карты в руке. Берём очередную карту и вставляем её на нужное место среди уже упорядоченных.

Слева – отсортированная часть массива. Берём следующий элемент `key`, сдвигаем на одну позицию вправо все элементы отсортированной части, которые больше `key`, и ставим `key` в освободившееся место.

```python
def insertion_sort(a):
    for i in range(1, len(a)):
        key = a[i]
        j = i - 1
        while j >= 0 and a[j] > key:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = key
```

<iframe src="sort-viz.htm#insertion" title="Анимация: сортировка вставками" style="width: 100%; height: 480px; border: none;"></iframe>

**Сложность.** В худшем случае (массив отсортирован в обратном порядке) каждый элемент сдвигается до самого начала – $O(n^2)$. Но если массив почти отсортирован, элементы почти не сдвигаются, и сортировка работает почти за $O(n)$. Поэтому вставками часто досортировывают небольшие и почти упорядоченные куски – так делает и встроенная сортировка Python.

## Сравнение

| | Пузырьком | Выбором | Вставками |
| --- | --- | --- | --- |
| Сравнений в худшем случае | $\frac{n(n-1)}{2}$ | $\frac{n(n-1)}{2}$ | $\frac{n(n-1)}{2}$ |
| Уже отсортированный массив | $O(n^2)$, с досрочным выходом $O(n)$ | $O(n^2)$ | $O(n)$ |
| Обменов или сдвигов | до $\frac{n(n-1)}{2}$ | ровно $n - 1$ | до $\frac{n(n-1)}{2}$ |
