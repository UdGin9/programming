## Задание 16 🌶️

Напишите функцию `count_if(numbers, condition)`, которая принимает список и **функцию-условие** и возвращает, для скольких элементов условие истинно.

```python
nums = [1, -2, 3, -4, 5, 6]
print(count_if(nums, lambda x: x > 0))       # 4
print(count_if(nums, lambda x: x % 2 == 0))  # 3
```
