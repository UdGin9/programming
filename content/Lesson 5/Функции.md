

Функции представляют блок кода, который выполняет определенную задачу и который можно повторно использовать в других частях программы. В предыдущих статьях уже использовались функции. В частности, функция `print()`, которая выводит некоторое значение на консоль.

Python имеет множество встроенных функций и позволяет определять свои функции. Формальное определение функции:

```python
def имя_функции ([параметры]):
    инструкции
```

Определение функции начинается с выражения `def`, которое состоит из имени функции, набора скобок с параметрами и двоеточия. Параметры в скобках необязательны. А со следующей строки идет блок инструкций, которые выполняет функция. Все инструкции функции имеют отступы от начала строки.

Например, определение простейшей функции:

```python
def say_hello():
    print("Hello")
```

Функция называется `say_hello`. Она не имеет параметров и содержит одну единственную инструкцию, которая выводит на консоль строку `"Hello"`.

Обратите внимание, что инструкции функции должны иметь отступы от начала строки. Например:

```python
def say_hello():
    print("Hello")


print("Bye")
```

Здесь инструкция `print("Bye")` не имеет отступов от начала функции `say_hello` и поэтому в эту функцию не входит. Обычно между определением функции и остальными инструкциями, которые не входят в функцию, располагаются две пустых строки.

Для вызова функции указывается имя функции, после которого в скобках идет передача значений для всех ее параметров:

```python
имя_функции ([параметры])
```

Например, определим и вызовем функцию:

```python
def say_hello():    # определение функции say_hello
    print("Hello")

say_hello()         # вызов функции say_hello
say_hello()
say_hello()
```

Здесь три раза подряд вызывается функция `say_hello`. В итоге мы получим следующий консольный вывод:

```
Hello
Hello
Hello
```

Обратите внимание, что функция сначала определяется, а потом вызывается.

Если функция имеет одну инструкцию, то её можно разместить на одной строке с остальным определением функции:

```python
def say_hello(): print("Hello")

say_hello()
```

Подобным образом можно определять и вызывать и другие функции. Например, определим и выполним несколько функций:

```python
def say_hello():
    print("Hello")

def say_goodbye():
    print("Good Bye")

say_hello()
say_goodbye()
```

Консольный вывод:

```
Hello
Good Bye
```

### Локальные функции

Одни функции могут определяться внутри других функций — внутренние функции ещё называют локальными. Локальные функции можно использовать только внутри той функции, в которой они определены. Например:

```python
def print_messages():
    # определение локальных функций
    def say_hello(): print("Hello")
    def say_goodbye(): print("Good Bye")
    # вызов локальных функций
    say_hello()
    say_goodbye()

# Вызов функции print_messages
print_messages()

# say_hello()  # вне функции print_messages функция say_hello не доступна
```

Здесь функции `say_hello()` и `say_goodbye()` определены внутри функции `print_messages()` и поэтому по отношению к ней являются локальными. Соответственно, они могут использоваться только внутри функции `print_messages()`.

### Организация программы и функция main

В программе может быть определено множество функций. И чтобы упорядочить их, одним из способов является добавление специальной функции (обычно называется `main`), в которой потом уже вызываются другие функции:

```python
def main():
    say_hello()
    say_goodbye()

def say_hello():
    print("Hello")

def say_goodbye():
    print("Good Bye")

# Вызов функции main
main()
```

## Параметры функции

Чаще всего функции нужно передать данные, с которыми она будет работать. Для этого при определении функции в скобках указываются **параметры**, а при вызове – **аргументы**, то есть конкретные значения этих параметров.

```python
def say_hello(name):
    print("Hello,", name)

say_hello("Tom")
say_hello("Bob")
```

выводит:

```no-highlight
Hello, Tom
Hello, Bob
```

Параметров может быть несколько. Аргументы передаются в том же порядке, в котором объявлены параметры:

```python
def print_person(name, age):
    print("Name:", name, "Age:", age)

print_person("Tom", 37)   # Name: Tom Age: 37
```

Если передать аргументов меньше или больше, чем параметров, программа завершится с ошибкой `TypeError`.

### Значения по умолчанию

Параметру можно задать значение по умолчанию – оно используется, если аргумент не передан:

```python
def say_hello(name="Tom"):
    print("Hello,", name)

say_hello()        # Hello, Tom
say_hello("Bob")   # Hello, Bob
```

**Запомни:** параметры со значением по умолчанию пишутся после обязательных: `def f(a, b=0)` – можно, `def f(a=0, b)` – ошибка.

### Именованные аргументы

Аргумент можно передать по имени параметра. Тогда порядок не важен:

```python
def print_person(name, age):
    print("Name:", name, "Age:", age)

print_person(age=22, name="Alice")   # Name: Alice Age: 22
```

С именованными аргументами вы уже встречались: `sep` и `end` у команды `print()` (см. [Print](<Print>)).

## Возврат результата: return

До сих пор наши функции только печатали. Но обычно функция должна **вычислить значение и вернуть его** в то место программы, откуда её вызвали. Для этого используется оператор `return`.

```python
def square(x):
    return x * x

a = square(5)
b = square(3) + square(4)
print(a, b)   # 25 25
```

Результат функции можно сохранить в переменную, использовать в выражении или сразу передать в другую функцию: `print(square(7))`.

### print и return – не одно и то же

Частая ошибка – печатать результат внутри функции вместо того, чтобы его вернуть:

```python
def square(x):
    print(x * x)

a = square(5)    # выведет 25
print(a)         # None
```

Функция без `return` возвращает специальное значение `None` – «ничего». С таким результатом нельзя считать дальше: `square(5) + 1` вызовет ошибку `TypeError`.

**Запомни:** `print` показывает значение человеку, `return` отдаёт значение программе. Если результат функции нужен дальше в коде – используйте `return`.

### return завершает функцию

Как только выполняется `return`, функция сразу заканчивает работу, и код после него не выполняется. Этим удобно пользоваться для досрочного выхода:

```python
def is_prime(n):
    if n < 2:
        return False
    for d in range(2, n):
        if n % d == 0:
            return False    # нашли делитель – дальше проверять незачем
    return True

print(is_prime(7))    # True
print(is_prime(12))   # False
```

> [!note] Примечание
> Эта функция правильная, но медленная для больших чисел. На следующем занятии (см. [Сложность алгоритмов](<Сложность алгоритмов>)) мы ускорим её в тысячи раз.

### Несколько значений

Функция может вернуть несколько значений через запятую. Их можно сразу распаковать в переменные, как список:

```python
def min_max(numbers):
    return min(numbers), max(numbers)

low, high = min_max([5, 11, 2, 8])
print(low, high)   # 2 11
```

## Область видимости переменных

Переменные, созданные внутри функции, называются **локальными**: они существуют только пока функция выполняется и не видны снаружи.

```python
def f():
    result = 42

f()
print(result)   # NameError: name 'result' is not defined
```

Переменные, созданные вне функций, называются **глобальными**. Функция может их читать, но если внутри функции присвоить значение переменной с тем же именем, будет создана новая локальная переменная, а глобальная не изменится:

```python
x = 10

def f():
    x = 5          # это новая, локальная x
    print(x)

f()          # 5
print(x)     # 10
```

Изменить глобальную переменную изнутри функции можно через ключевое слово `global`, но так делать не рекомендуется: такой код сложно читать и проверять. Правильный способ – передать данные через параметры и получить результат через `return`:

```python
# плохо
total = 0

def add(x):
    global total
    total += x


# хорошо
def add(total, x):
    return total + x
```

## Функция как значение и lambda

В Python функцию можно передать в другую функцию как обычное значение. Например, `sorted()` и `sort()` принимают параметр `key` – функцию, по результату которой сравниваются элементы:

```python
words = ["кот", "собака", "ёж", "лиса"]
print(sorted(words, key=len))   # ['ёж', 'кот', 'лиса', 'собака']
```

Обратите внимание: `len` передаётся **без скобок** – мы передаём саму функцию, а не результат её вызова.

Для коротких функций, которые нужны в одном месте, используют **lambda-выражения** – функции без имени, записанные в одну строку:

```python
square = lambda x: x * x      # то же, что def square(x): return x * x
print(square(4))              # 16

students = [{"name": "Alice", "grade": 85}, {"name": "Bob", "grade": 60}]
best = max(students, key=lambda s: s["grade"])
print(best["name"])           # Alice
```

Такие выражения мы уже видели в функции `filter()` (см. [Списки](<Списки>)).

## Зачем функции в задачах

Функции помогают разбить задачу на маленькие части, каждую из которых легко написать и проверить отдельно. Например, задача «вывести все простые числа от 1 до N» сводится к функции `is_prime` из примера выше и простому циклу:

```python
n = int(input())
for i in range(1, n + 1):
    if is_prime(i):
        print(i, end=" ")
```

Если программа работает неправильно, функцию можно проверить отдельно на нескольких значениях: `print(is_prime(1), is_prime(2), is_prime(9))` должно вывести `False True False`.

## Шпаргалка

| Что нужно | Код |
| --------- | --- |
| функция с параметрами | `def f(a, b):` |
| значение по умолчанию | `def f(a, b=0):` |
| именованный аргумент | `f(b=5, a=1)` |
| вернуть результат | `return a + b` |
| вернуть несколько значений | `return x, y` и `x, y = f()` |
| короткая функция без имени | `lambda x: x * 2` |
| передать функцию как ключ | `sorted(words, key=len)` |
