# Часть 1. Строки

## Задача 1. Разбор строки

Дана строка. Выведите (каждое на новой строке): её длину, первый символ, последний символ и строку задом наперёд.

```no-highlight
Ввод:
Python

Вывод:
6
P
n
nohtyP
```

## Задача 2. Гласные

Дана строка на русском языке. Посчитайте, сколько в ней гласных букв (а, е, ё, и, о, у, ы, э, ю, я). Заглавные буквы тоже считаются.

```no-highlight
Ввод:
Привет, Мир!

Вывод:
3
```

## Задача 3. Палиндром

Проверьте, является ли строка палиндромом без учёта пробелов и регистра букв. Выведите «ДА» или «НЕТ».

```no-highlight
Ввод:
А роза упала на лапу Азора

Вывод:
ДА
```

## Задача 4. Количество слов

Дана строка, слова в которой разделены одним или несколькими пробелами. В начале и в конце строки тоже могут быть пробелы. Выведите количество слов.

```no-highlight
Ввод:
   мама   мыла раму  

Вывод:
3
```

## Задача 5. Самое длинное слово

Дана строка из слов, разделённых пробелами. Выведите самое длинное слово. Если таких слов несколько – выведите первое из них.

```no-highlight
Ввод:
Я изучаю программирование на Python

Вывод:
программирование
```

## Задача 6. Сумма цифр

Дана строка из букв и цифр. Найдите сумму всех цифр в ней.

```no-highlight
Ввод:
a1b2c33

Вывод:
9
```

## Задача 7. Шифр Цезаря 🌶️

В шифре Цезаря каждая буква заменяется на букву, стоящую в алфавите на $k$ позиций дальше. Алфавит считается замкнутым: после `z` снова идёт `a`.

Дана строка из строчных латинских букв, пробелов и знаков препинания и число $k$ ($0 \le k \le 25$). Зашифруйте строку. Символы, которые не являются буквами, оставьте без изменений.

```no-highlight
Ввод:
hello, world!
3

Вывод:
khoor, zruog!
```

> [!hint] Подсказка
> Номер буквы в алфавите: `ord(c) - ord('a')`. Чтобы алфавит был замкнутым, возьмите остаток от деления на 26.

## Задача 8. Сжатие строки 🌶️

Сожмите строку: каждую группу подряд идущих одинаковых символов замените на символ и количество его повторений.

```no-highlight
Ввод:
aaabccdddd

Вывод:
a3b1c2d4
```

# Часть 2. Оценка сложности

## Задача 9. Определите сложность

Для каждого фрагмента определите сложность в O-нотации и коротко объясните ответ. Везде `a` – список из $n$ чисел.

**а)**
```python
for i in range(n):
    for j in range(n):
        print(i + j)
```

**б)**
```python
i = 1
while i < n:
    i *= 2
```

**в)**
```python
for i in range(n):
    print(i)
for j in range(n):
    print(j)
```

**г)**
```python
for i in range(n):
    for j in range(10):
        print(i * j)
```

**д)**
```python
for x in a:
    if a.count(x) > 1:
        print(x)
```

**е)**
```python
while len(a) > 0:
    a.pop(0)
```

**ж)**
```python
cnt = 0
for i in range(n):
    for j in range(i + 1, n):
        if a[i] + a[j] == 0:
            cnt += 1
```

**з)**
```python
while n > 0:
    n //= 10
```

# Часть 3. Задачи с ограничениями

В этих задачах важна не только правильность, но и скорость. Перед тем как писать код, оцените сложность своего решения и проверьте, уложится ли оно в 1 секунду при максимальных ограничениях (см. [Сложность алгоритмов](<Сложность алгоритмов>)).

## Задача 10. Сумма на отрезке

Дан список из $n$ целых чисел и $q$ запросов. Для каждого запроса $l$, $r$ выведите сумму элементов с $l$-го по $r$-й включительно (элементы нумеруются с единицы).

**Формат входных данных**

В первой строке – число $n$ ($1 \le n \le 10^5$). Во второй строке – $n$ целых чисел через пробел, каждое по модулю не больше $10^9$. В третьей строке – число $q$ ($1 \le q \le 10^5$). Далее $q$ строк, в каждой два числа $l$ и $r$ ($1 \le l \le r \le n$).

**Формат выходных данных**

Для каждого запроса выведите ответ на отдельной строке.

```no-highlight
Ввод:
5
3 1 4 1 5
3
1 5
2 4
3 3

Вывод:
14
6
4
```

> [!question] Вопрос
> Сколько операций сделает решение, которое для каждого запроса считает `sum(a[l - 1:r])`? Почему оно не пройдёт по времени?

## Задача 11. Большое простое число

Дано натуральное число $n$ ($1 \le n \le 10^{12}$). Определите, является ли оно простым. Выведите «ДА» или «НЕТ». Число 1 простым не является.

```no-highlight
Ввод:
1000000007

Вывод:
ДА
```

```no-highlight
Ввод:
12

Вывод:
НЕТ
```

## Задача 12. Сумма остальных

Дан список из $n$ целых чисел ($1 \le n \le 10^5$). Для каждого элемента выведите сумму всех **остальных** элементов. Ответы выведите в одну строку через пробел.

```no-highlight
Ввод:
4
1 2 3 4

Вывод:
9 8 7 6
```

> [!hint] Подсказка
> Решение с вложенным циклом работает за $O(n^2)$. Подумайте, как сделать за $O(n)$.

## Задача 13. Чётные на отрезке 🌶️

Дан список из $n$ целых чисел и $q$ запросов ($1 \le n, q \le 10^5$). Для каждого запроса $l$, $r$ выведите, сколько чётных чисел среди элементов с $l$-го по $r$-й. Формат ввода такой же, как в задаче 10.

```no-highlight
Ввод:
6
2 7 4 4 9 1
3
1 6
2 3
5 6

Вывод:
3
1
0
```

## Задача 14. Лучшее окно 🌶️🌶️

Дан список из $n$ целых чисел и число $k$ ($1 \le k \le n \le 10^5$). Найдите максимальную сумму $k$ подряд идущих элементов.

**Формат входных данных**

В первой строке – числа $n$ и $k$ через пробел. Во второй строке – $n$ целых чисел через пробел.

**Формат выходных данных**

Одно число – максимальная сумма.

```no-highlight
Ввод:
5 2
1 3 -2 5 1

Вывод:
6
```
