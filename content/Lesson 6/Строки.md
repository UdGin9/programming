Строка (`str`) – это последовательность символов. Строки записываются в одинарных или двойных кавычках: `'Python'` и `"Python"` – одна и та же строка.

Почти в каждой задаче на вход приходит текст, поэтому умение работать со строками нужно постоянно.

## Длина, индексы и срезы

Строка устроена почти как список символов: у каждого символа есть индекс, отсчёт начинается с нуля.

| Символ          | P   | y   | t   | h   | o   | n   |
| --------------- | --- | --- | --- | --- | --- | --- |
| Индекс          | 0   | 1   | 2   | 3   | 4   | 5   |
| Индекс с конца  | -6  | -5  | -4  | -3  | -2  | -1  |

```python
s = "Python"
print(len(s))    # 6
print(s[0])      # P
print(s[-1])     # n
print(s[1:4])    # yth
print(s[::-1])   # nohtyP – строка задом наперёд
```

Срезы работают так же, как у списков (см. [Списки](<Списки>)).

## Строки неизменяемы

В отличие от списка, символ строки нельзя заменить по индексу:

```python
s = "Python"
s[0] = "J"    # TypeError: 'str' object does not support item assignment
```

Вместо этого нужно собрать новую строку:

```python
s = "J" + s[1:]
print(s)      # Jython
```

## Перебор символов

Строку можно перебрать в цикле `for` – так же, как список:

```python
s = "hello"
for c in s:
    print(c)
```

Если нужен ещё и индекс символа – перебираем индексы:

```python
for i in range(len(s)):
    print(i, s[i])
```

Пример: посчитать, сколько цифр в строке.

```python
s = input()
count = 0
for c in s:
    if c.isdigit():
        count += 1
print(count)
```

## Операции со строками

| Операция | Описание | Пример |
| -------- | -------- | ------ |
| `+` | склеивание (конкатенация) | `"ab" + "cd"` → `"abcd"` |
| `*` | повторение | `"ab" * 3` → `"ababab"` |
| `in` | содержится ли подстрока | `"th" in "Python"` → `True` |
| `==`, `!=` | равны ли строки | `"abc" == "abc"` → `True` |
| `<`, `>` | сравнение по алфавиту | `"apple" < "banana"` → `True` |

### Сравнение строк

Строки сравниваются **лексикографически** – посимвольно, как слова в словаре: сначала сравниваются первые символы, если они равны – вторые, и так далее.

```python
print("apple" < "banana")   # True:  'a' < 'b'
print("cat" < "car")        # False: 't' > 'r'
print("ab" < "abc")         # True:  более короткое начало меньше
```

**Обратите внимание:** символы сравниваются по их кодам (см. ниже), поэтому заглавные буквы «меньше» строчных, а числа в виде строк сравниваются не как числа:

```python
print("Z" < "a")     # True
print("10" < "9")    # True – сравниваются символы '1' и '9'
print(10 < 9)        # False
```

**Запомни:** если сравниваете числа – сначала преобразуйте их через `int()`.

## Коды символов: ord и chr

Каждый символ хранится в компьютере как число – его код в таблице Unicode. Функция `ord()` возвращает код символа, а `chr()` – символ по коду:

```python
print(ord('a'))   # 97
print(ord('b'))   # 98
print(ord('A'))   # 65
print(chr(97))    # a
```

Буквы латинского алфавита идут подряд, поэтому номер буквы в алфавите можно получить вычитанием:

```python
c = 'd'
print(ord(c) - ord('a'))   # 3 (a – 0, b – 1, c – 2, d – 3)
print(chr(ord(c) + 1))     # e – следующая буква
```

> [!note] Примечание
> Русские буквы от «а» до «я» тоже идут подряд, но буква «ё» стоит отдельно: `ord('а')` = 1072, `ord('я')` = 1103, а `ord('ё')` = 1105.

## Методы строк

Метод вызывается через точку после строки: `s.upper()`. **Методы не изменяют строку, а возвращают новую**:

```python
s = "Python"
s.upper()
print(s)          # Python – строка не изменилась
s = s.upper()
print(s)          # PYTHON
```

| Метод | Описание | Пример |
| ----- | -------- | ------ |
| `s.lower()`, `s.upper()` | все буквы строчные / заглавные | `"PyThOn".lower()` → `"python"` |
| `s.strip()` | убрать пробелы и переводы строк по краям | `"  hi  ".strip()` → `"hi"` |
| `s.split()` | разбить по пробелам на список слов | `"a  b c".split()` → `['a', 'b', 'c']` |
| `s.split(sep)` | разбить по разделителю | `"1,2,3".split(",")` → `['1', '2', '3']` |
| `sep.join(список)` | склеить список строк через разделитель | `"-".join(['a', 'b'])` → `"a-b"` |
| `s.replace(a, b)` | заменить все `a` на `b` | `"мама".replace("м", "п")` → `"папа"` |
| `s.find(sub)` | индекс первого вхождения, `-1` если нет | `"hello".find("l")` → `2` |
| `s.count(sub)` | сколько раз встречается подстрока | `"hello".count("l")` → `2` |
| `s.startswith(x)`, `s.endswith(x)` | начинается / заканчивается ли на `x` | `"file.py".endswith(".py")` → `True` |
| `s.isdigit()` | состоит ли только из цифр | `"123".isdigit()` → `True` |
| `s.isalpha()` | состоит ли только из букв | `"abc1".isalpha()` → `False` |

**Запомни:** `split()` без аргументов делит строку по любому количеству пробелов, а `split(" ")` – строго по одному пробелу: `"a  b".split(" ")` → `['a', '', 'b']`.

### join и вывод списка

Метод `join()` склеивает только строки. Чтобы вывести список чисел через пробел, числа сначала превращают в строки:

```python
nums = [1, 2, 3]
print(" ".join(map(str, nums)))   # 1 2 3
print(*nums)                      # 1 2 3 – то же самое, короче
```

## Форматированный вывод: f-строки

Если перед строкой поставить букву `f`, внутри фигурных скобок можно писать переменные и выражения:

```python
name = "Анна"
age = 19
print(f"{name}, {age} лет")       # Анна, 19 лет
print(f"Через год: {age + 1}")    # Через год: 20
```

f-строки удобны, когда в задаче нужно вывести число с заданной точностью:

```python
x = 3.14159
print(f"{x:.2f}")    # 3.14 – два знака после точки
print(f"{x:.4f}")    # 3.1416
```

## Сборка строки по частям

Так как строки неизменяемы, каждая операция `s += ...` может создавать новую строку и копировать в неё всё старое содержимое. Для длинных строк надёжнее собрать части в список и склеить один раз:

```python
parts = []
for i in range(1, 6):
    parts.append(str(i * i))
print(" ".join(parts))   # 1 4 9 16 25
```

Почему это важно, разберём в теме [Сложность алгоритмов](<Сложность алгоритмов>).

## Шпаргалка

| Что нужно | Код |
| --------- | --- |
| длина строки | `len(s)` |
| символ по индексу / последний | `s[i]`, `s[-1]` |
| строка задом наперёд | `s[::-1]` |
| перебрать символы | `for c in s:` |
| список слов | `s.split()` |
| склеить список через пробел | `" ".join(words)` |
| вывести список чисел через пробел | `print(*nums)` |
| код символа и обратно | `ord(c)`, `chr(n)` |
| номер латинской буквы в алфавите | `ord(c) - ord('a')` |
| число с двумя знаками | `f"{x:.2f}"` |
