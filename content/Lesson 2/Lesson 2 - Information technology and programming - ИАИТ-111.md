# Занятие № 2

## Материалы

- [Информация по построению блок-схем](<Правила построения блок схем.md>)

## Задание

Построить блок-схемы для каждой из задач. Оформление — по правилам ГОСТ 19.701 (см. [Правила построения блок схем](<Правила построения блок схем.md>)): присваивание записывать как `:=`, сравнение на равенство — одним знаком `=`. Рисовать можно от руки или в draw.io.

1. Вычислить гипотенузу прямоугольного треугольника по двум катетам a и b: c := √(a² + b²)
2. Найти среднее арифметическое трёх введённых чисел a, b и c
3. Дано число x. Вывести модуль числа: если x ≥ 0, вывести x, иначе вывести −x
4. Даны два числа a и b. Вывести большее из них
5. Вводится натуральное число N. Найти сумму чисел от 1 до N
6. Вводится натуральное число N. Вычислить факториал N! := 1 · 2 · … · N
