До этого момента мы передавали данные программе прямо в коде. Но программы должны уметь работать с любыми данными, которые вводит пользователь. Для этого в Python существует команда `input()`.

## Обычный ввод — любое значение

Команда `input()` считывает одну строку, которую пользователь ввёл с клавиатуры, и **всегда возвращает строку** (`str`), независимо от того, что было введено.

```python
name = input()
print('Привет,', name)
```

Если пользователь введёт число, например `17`, переменная `name` всё равно будет содержать строку `'17'`.

В команду `input()` можно передать строку-приглашение — она выводится перед местом ввода:

```python
name = input('Как тебя зовут? ')
print('Привет,', name)
```

**Запомни:** команда `input()` считывает данные **только до конца строки** (до нажатия Enter). Если пользователь ввёл несколько чисел через пробел, `input()` вернёт всё это как одну строку.

## Преобразование типов

Чтобы работать с введёнными данными как с числами, строку нужно преобразовать:

```python
num = int(input())      # целое число (int)
x = float(input())      # вещественное число (float)
s = input()             # строка (str), преобразование не нужно
```

Функция `int()` преобразует строку в целое число, а `float()` — в число с плавающей точкой. Если строка не является числом (например, `int('abc')`), программа завершится с ошибкой.

## Два вида ввода с клавиатуры

Если программе нужно несколько значений, их можно ввести двумя способами.

### Построчный ввод

Каждое значение вводится с новой строки:

```python
num1 = int(input())
num2 = int(input())
num3 = int(input())
```

Благодаря множественному присваиванию ту же запись можно сократить до одной строки:

```python
num1, num2, num3 = int(input()), int(input()), int(input())
```

### Однострочный ввод

Все значения вводятся в одну строку через пробел. Метод `split()` разбивает строку на части по пробелам и возвращает список строк, а функция `map()` применяет преобразование к каждому элементу:

```python
num1, num2, num3 = map(int, input().split())
```

Если пользователь ввёл `1 2 3`, то в переменных окажутся числа `1`, `2` и `3`. Количество введённых значений должно совпадать с количеством переменных слева, иначе программа завершится с ошибкой.

**Запомни:** два основных вида ввода — построчный (`num = int(input())` для каждого числа) и однострочный через пробел (`a, b = map(int, input().split())`).

## Ввод списка (массива)

Иногда количество вводимых значений заранее неизвестно, и нужно получить их все в виде списка. Для этого результат `map()` оборачивается в функцию `list()`:

```python
numbers = list(map(int, input().split()))   # список целых чисел
words = input().split()                      # список строк
```

Если пользователь ввёл `5 11 2 8`, то `numbers` будет равен `[5, 11, 2, 8]`.

## Модуль math

Для математических вычислений используют функции модуля `math`, который подключается в начале программы:

```python
import math
```

| Функция          | Описание                                        |
| ---------------- | ----------------------------------------------- |
| `sqrt(x)`        | квадратный корень                               |
| `pi`             | число $\pi$                                     |
| `sin(x)`, `cos(x)`, `tan(x)` | синус, косинус, тангенс (угол в радианах) |
| `radians(x)`     | перевод угла из градусов в радианы              |
| `floor(x)`       | округление вниз («пол» числа)                   |
| `ceil(x)`        | округление вверх («потолок» числа)              |

## Шпаргалка

| Что нужно считать | Код |
| ----------------- | --- |
| строку | `s = input()` |
| целое число | `n = int(input())` |
| вещественное число | `x = float(input())` |
| несколько чисел с новой строки | `a, b = int(input()), int(input())` |
| несколько чисел в одну строку | `a, b = map(int, input().split())` |
| список чисел | `nums = list(map(int, input().split()))` |
